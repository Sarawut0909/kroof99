K-Roof เว็บเวอร์ชันแก้ไข

หน้าแรก:
- ใต้แต่ละรูปมีเพียง "สอบถามราคา"
- ไม่มีปุ่ม "รายละเอียดแผ่น" และ "ข้อมูลสินค้า" อีกแล้ว
- กดรูปสินค้า -> เข้า "หน้ารายละเอียดสินค้า"

หน้ารายละเอียด:
- แสดงรายละเอียดของแผ่น
- แสดงรูปสินค้าเพิ่มเติมด้านล่าง
- กดรูปด้านล่างเพื่อเปิดรูปใหญ่
- ลูกศรซ้าย/ขวาเลื่อนรูปได้
- ESC ปิดรูปใหญ่
