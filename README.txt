K-Roof เวอร์ชันแก้ไข

แก้ปัญหาสินค้าหาย:
- ใช้หน้าเว็บรุ่นที่มี productGrid และ JavaScript ที่ทำงานอยู่เดิมเป็นฐาน
- เพิ่มเมนูสีน้ำเงินด้านซ้ายโดยไม่ลบ section สินค้า
- ผลิตภัณฑ์ / โรงจอดรถ / กันสาด / โครงหลังคา
- สินค้าทั้งหมดกลับมาแสดง
- ปุ่มสอบถามราคาเป็นสีเหลืองตามแบบ
- กดรูปสินค้าเข้าไปหน้ารายละเอียด และกดรูปเพิ่มเติมดูใหญ่ได้
