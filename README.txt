K-Roof Offline Website
วิธีใช้:
1. เปิดไฟล์ index.html ด้วย Chrome/Edge/Safari
2. เว็บใช้งานได้โดยไม่ต้องมีอินเทอร์เน็ตสำหรับตัวเว็บ
3. กด "จัดการรูป" เพื่อเพิ่มรูปสินค้าและรูปบริการภายหลัง
4. รูปที่เพิ่มจะเก็บในเบราว์เซอร์เครื่องนั้นด้วย IndexedDB
5. ปุ่มโทร/LINE ต้องใช้อินเทอร์เน็ต/เครือข่ายเพื่อทำงานจริง

หมายเหตุ:
- เวอร์ชันนี้เป็นโครงสร้างเว็บเริ่มต้น เน้นให้เพิ่มรูปภายหลังได้
- สามารถต่อยอดเป็นระบบหลังบ้าน, ราคา, รายละเอียดสินค้า, แกลเลอรี, ฟอร์มสอบถาม และนำขึ้นออนไลน์ได้
